# Проект для самообучения - что есть в Opencode и как с инм работать
  Исследуем возможности opencode реализуя игру морской бой с помощью 2-х агентов
   - игры
   - адмиралов - игроков
   Игра - стартовый агент, который выступает координатором 2-х сабагетов игроков, обменивающися выстрелами.
   Первым был создан ьазовый AGENTS.md (ставший AGENTS.bak) - из которого все остально еполучено исключительно зазапросами к ЛЛМ тиа - улучши, добавь возможность.

   в каталоге содержаться 3 проекта игры, где 01 -первичный, 02 - получен копированием и преобразованием из 01, а 03 из 02.

##  Содержимое
 - ai_sea_battle_01  - первый вариант игры, сознательно сделан с кастомной файловой структурой агентов инструкций и тп. в файлах нет ничего, что отвечало бы
                       структуре opencode. В инструкции есть токо строчка, что надо сооздать opencode.json, где эта кастомная структура была бы расписана чем она являкется в opencode/

                       Вся конфигурация opencode лежит в 1 файле со всеми атрибутами файлов, то это отличный вариант увидеть о сущьностях  opencode:
                        - интструкции - первичная загрузка
                        - агенты  - агенгты, субагенты, скрытые(тока из агентов), вызов по @ - mode=subagent | all, hidden=false), локальный контекст
                        - команды - вызываем агентов с параметрами
                        - инструменты - первичная загрузка
                        - task - создает отдельную сессию (в проекте 02).

                        Эксперименты с изменением контекста командами агентами и тп - никак кроме прямой команды загрузки инструкции.
                        Инструменты для агентов - редактор (локализацяи места записи), поиск, таск
                        Команды - удобно запускать агенты с параметрами
                        ------------------
                        В любой момент можно попросить  перевести формат проекта в макс соотв опенкоде, вынеся все что можно в заголовки файлов и макс уменьшив ЖСОН.
                        И наоборот.  - очень наглядно.

 - ai_sea_battle_02 - здесь почти тот же проект (01), но сделан строго под opencode, все атрибуты внесены в файлы, opencode.json сделан минимально возможным.
 - ai_sea_battle_03 - здесь были эксперименты с ускорением работы игры. Спойлер - выполнена оптимизация логики работы. доп каналы не ускоряют.
