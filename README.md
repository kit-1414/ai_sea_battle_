# Agents Sea Battle

Учебная мультиагентная игра «Морской бой». Универсальный координатор управляет двумя независимыми сессиями адмирала, которые играют за синюю и зелёную стороны. Инструкции отделены от конфигурации конкретной ИИ-платформы.

## Структура

- `.ai_files_dir/agents/battle-field.md` - инструкция координатора игры.
- `.ai_files_dir/agents/admiral.md` - инструкция игрока.
- `.ai_files_dir/commands/sea-battle.md` - сценарий запуска.
- `.ai_files_dir/README.md` - требования к интеграционному адаптеру.
- `opencode.json` - адаптер для OpenCode.
- `AGENTS.md` - общие правила и протокол игры.

## Запуск в OpenCode

1. Открыть корень проекта в OpenCode с настроенным провайдером OpenAI.
2. После установки или изменения `opencode.json` либо файлов `.ai_files_dir` полностью перезапустить OpenCode.
3. Запустить игру с полем 10x10:

```text
/sea-battle
```

Для квадратного поля другого размера передать целое число не меньше 5:

```text
/sea-battle 12
```

По завершении игры результат выводится в диалоге, а статистика сохраняется в `stats/blue.json` и `stats/green.json`.

## Другие ИИ-платформы

Инструкции в `.ai_files_dir` не содержат YAML-frontmatter, названий инструментов OpenCode или привязки к модели. Для другой платформы создайте адаптер, который зарегистрирует роли, подключит эти Markdown-файлы и обеспечит постоянные сессии игроков. Полный список требований находится в `.ai_files_dir/README.md`.
