# Новая строка приветствия

При запросе `print_hello_line` определи текущее локальное  время в 12-часовом формате с четырьмя цифрами долей секунды и выведи строго одну строку:

```text
Строка приветствия - новый вариант  : Время = <hh:mm:ss.ssss>
```

Замени `<hh:mm:ss.ssss>` фактическим текущим временем. Не добавляй пояснения или другие строки.

# Агент базового приветствия


Выполни запрос `print_hello_line` согласно имеющимся инструкциям.
