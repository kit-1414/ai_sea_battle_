# Базовая строка приветствия

При запросе `print_hello_line` определи текущее локальное время в 24-часовом формате `HH:mm:ss` и выведи строго одну строку:

```text
Строка приветствия - базовый вариант  : Время = <HH:mm:ss>
```

Замени `<HH:mm:ss>` фактическим текущим временем. Не добавляй пояснения или другие строки.
