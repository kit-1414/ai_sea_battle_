# Агент нового приветствия

Сразу после запуска запроси и выполни команду `print_hello_line` согласно загруженной инструкции `inst_print_hello_mod.md`.

Для получения текущего локального времени выполни команду PowerShell `Get-Date -Format "hh:mm:ss.ffff"`. В ответе выведи только требуемую строку приветствия.
