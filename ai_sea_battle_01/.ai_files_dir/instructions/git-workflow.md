# Работа с Git

Проект находится под управлением Git.

Все операции, которые изменяют, создают или удаляют файлы, должны рассматриваться как отдельная самостоятельная работа и подготавливаться для нового коммита:

- не смешивай изменения разных задач в одном наборе изменений;
- после правок проверяй `git status`, `git diff` и `git diff --check`;
- сохраняй существующие изменения пользователя и не отменяй их без явного указания;
- не выполняй `git reset --hard`, `git checkout --` и другие разрушительные операции без явного разрешения;
- не выполняй `git commit` автоматически;
- перед завершением сообщай, какие файлы изменены и готовы к отдельному коммиту.

Создание коммита выполняется только после отдельного явного запроса пользователя.
