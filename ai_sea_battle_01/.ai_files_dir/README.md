# Инструкции агентов

Каталог содержит универсальные инструкции морского боя и workflow массовой реализации для OpenCode:

- `agents/battle-field.md` - координатор игры;
- `agents/admiral.md` - игрок с сохраняемым состоянием;
- `agents/mass_agent_start.md` - координатор массовой реализации задачи;
- `agents/mass_agent_plan.md` - планировщик задачи;
- `agents/mass_agent_implement.md` - реализатор одного patch;
- `commands/sea-battle.md` - сценарий запуска игры.

Skills в `instructions/plan/`, `instructions/plan-implement/` и `instructions/plan-review/` задают общий формат `.ai/plans/NN_plan_name/`, информационные границы и правила проверки. Подготовительный шаг реализации только проверяет состояние Git: автоматические staging и commit запрещены.

Интеграционный конфиг конкретной платформы должен:

- зарегистрировать координатора как основного агента;
- зарегистрировать адмирала как скрытого или внутреннего субагента;
- разрешить координатору создавать только экземпляры адмирала;
- обеспечить продолжение каждой сессии адмирала по постоянному идентификатору;
- разрешить адмиралу запись только собственного файла `../stats/<name>.json`;
- передать координатору необязательный размер поля.

Адаптер OpenCode находится в корневом файле `../opencode.json`.

## Адаптер массовой реализации

Интеграционный конфиг должен:

- зарегистрировать `mass_agent_start` как основного агента на модели Luna;
- зарегистрировать `mass_agent_plan` как скрытого субагента на модели Sol с максимальным доступным вариантом рассуждения;
- зарегистрировать `mass_agent_implement` как скрытого субагента на модели Luna;
- предоставить планировщику skill `plan` и запись в `.ai/plans/**`;
- предоставить реализатору skill `plan-implement`, редактирование проекта и запуск проверок;
- разрешить координатору запускать только два mass-субагента;
- сохранять `task_id` заблокированной сессии до получения ответа пользователя;
- запускать отдельную сессию реализатора для каждого patch и выполнять patches последовательно;
- не разрешать автоматические staging, commit или откат пользовательских изменений.
