задача

Требуется разработать несколько агентов, которые работают совместно.
все агенты имеют настройку на имя модели в которой работают.
для агентов на основе данной задачи написать тело с описанием того что они делают. Файл с телом положить в пвпку .ai_files_dir/agents
всех 3-х агентов добавить в конфигурацию opencode.json с учетом загружаемых скилов-инструкций и модели для использования.

1.  первый агент - "mass_agent_start" Он доступен из консоли opencode по "/". 
    Агент работает в модели Luna. Это фиксируется в конфигурацию opencode.json
    данный агент получает на вход описание задачи от человека. Работает с человеком уточняя формулировки задачи. 
    После подтверждению готовности формулировки задачи он 
    - создает рабочую папаку в проекте (имя папки уточнить у человека)
    - записыват формулировку задачи в файл в этой папке с названием "task_definition.md"
    - вызывает агент планировшика "mass_agent_plan", перелдавая ему на вход имя файла с формулировкой задания.
    - получает от планировщика список этапов реализации и для каждого этапа по очереди вызывает агента  "mass_agent_implement" для реализации передавая ему имя файла с планом данного шага.

2. Второй агент "mass_agent_plan". Принимает на вход имя файла с формулировкой задачи. 
    Агент работает в модели Sol с макс размером контекста и возможностями.Это фиксируется в конфигурацию opencode.json
    Данный агент:
    - при старте загружает в свой контекст себе все инструкции из папки "/instructions/plan/*"
    - читает файл с заданием. Составляет план рабьоты (при необхожимости задавая вопросы человеку. Но только когда это крайне необходимо.)
    - после составления плана он разбивает план на несколько небольших изолированных шагов. Все шаги записывает в рабочей папку в файлы с именами "implementation_step_N.md"
      где буква N - это номер шага.
    - возвращает список файлов основному агенту

3. Третий агент "mass_agent_implement". Принимает на вход имя файла с описанием того что надо реализовать. 
    Агент работает в модели Luna.Это фиксируется в конфигурацию opencode.json
    Данный агент:
    - при старте загружает в свой контекст себе все инструкции из папки "/instructions/plan-implement/*" 
    - читает файл с планом работ. Выполняет его (при необхожимости задавая вопросы человеку. Но тольео когда это крайне необходимо.)
    - завершает работу
